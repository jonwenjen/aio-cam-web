# M1 iPhone 實機驗收

裝置：iPhone 18 Pro Max（Safari）。網址：https://jonwenjen.github.io/aio-cam-web/?debug=1
每一步只做一個動作；做完把結果填進下方表格，或直接把數字告訴 Claude。

## 準備（一次就好）

- 相機設定：**設定 → 相機 → 格式 → 最相容**（存 JPEG，才有 HDR 增益圖），並開啟 48MP（解析度控制）。
- 先用相機 App 拍幾張照片，至少要有：1 張**有 GPS 的 48MP HDR 照片**（戶外、有亮部最好），以及步驟 8 要用的 10 種場景。

## 步驟

1. 用 Safari 開啟上面的網址。按下方的**分享**按鈕 →「**加入主畫面**」→「新增」。
2. 從主畫面開啟 **AIO Cam**。按「**選擇照片**」，選那張有 GPS 的 48MP HDR 照片。
3. 在發色列點「**日和**」。確認存檔鈕上方的隱私開關是「**保留全部**」。
4. 按「**存檔**」→ 分享面板 →「**儲存影像**」。按右上角「**除錯**」，記下「lastExport → timings → **total**」毫秒數（**S1：≤ 2000**）。
5. 隱私開關改成「**去除位置**」→ 存檔 → 儲存影像。
6. 隱私開關改成「**去除全部**」→ 存檔 → 儲存影像。
7. 點「**原色**」，隱私開關改回「**保留全部**」→ 存檔 → 儲存影像（S2 用）。
8. 打開**照片 App**，找到原圖 → 分享 →「**選項**」→ 開啟「**所有照片資料**」→ AirDrop 到 Mac mini。再把剛存的 **4 張輸出**也 AirDrop 過去（檔名都是 `AIO_…`）。
9. 開**飛航模式**。從主畫面重新開啟 AIO Cam，選一張照片並存檔，確認離線也能用。關掉飛航模式。
10. 主觀比較：在照片 App 並排看**原圖**與「**原色**」輸出，亮部（天空、反光）是否一樣亮。
11. 自動推薦：逐張匯入 10 張不同場景的照片（人像、藍天、夜景、室內、陰天、綠地、逆光、霓虹、黃金時刻、高反差）。每張記下推薦的 3 組發色與理由；按「**自動**」後比原圖好、差不多或變差；以及除錯面板的「**autoMs**」（**S20：≤ 50 ms**）。

12. **HEIC 直拍**：相機格式暫時改回「高效率」，直拿手機拍一張 → 匯入 → 預覽是正的、沒有被壓扁 → 存檔成功（M1 的 HEIC 一律存 SDR，第一次會出現「想保留 HDR…」提示）。拍完把格式改回「最相容」。
13. **直拍 HDR JPEG**：匯入一張直拿手機拍的「最相容」照片 → 預覽是正的 → 存檔後在照片 App 看也是正的。
14. **取消分享**：存檔 → 分享面板按「取消」→ 不應出現錯誤訊息；再按一次存檔鈕 → 分享面板**立刻**出現（不會再顯示「處理中…」）。
15. **手勢過期後改隱私**：如果存檔後按鈕變成「點這裡分享／儲存」，先把隱私開關改成「去除位置」→ 按鈕應變回「存檔」→ 再存一次，確認這次存的檔案沒有位置（照片 App 的資訊面板看不到地圖）。
16. **VoiceOver**（設定 → 輔助使用 → 旁白）：用旁白依序點「自動」、一個發色、隱私開關、存檔，每個控制項都應念出名稱。

AirDrop 完成後告訴 Claude，Claude 會執行：

```
tools/device-run.sh ~/Downloads/<原圖>.jpg ~/Downloads/AIO_…_asshot.jpg ~/Downloads/AIO_…_hiyori.jpg <去除位置那張> <去除全部那張>
```
